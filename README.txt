SHOKOLBAZAR — STATIC HTML STARTER

FILES
- index.html: homepage structure and sample product content
- style.css: responsive styling (light sky-blue brand palette)
- script.js: demo cart counter and toast message
- images/: editable SVG artwork used by the homepage

HOW TO PREVIEW
1. Extract this ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. To publish, upload the contents of this folder (not the ZIP itself) to your hosting public_html folder.

IMPORTANT
This is a static front-end starter, not a complete ecommerce backend.
The cart is only a browser demo. It does not save orders, customer accounts, stock, payments, or admin edits.
Product names, prices and artwork are sample content. Replace them with your actual products and approved images.
The Google Fonts import requires an internet connection; system fonts are used as fallback.
